## 💻 How to Run the Code Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. **Navigate into the project directory**:
   ```bash
   cd "My JS"
   ```
3. **Run any script with Node.js**:
   ```bash
   node index.js
   ```
   *(Alternatively, run HTML/JS files in any modern web browser or VS Code Live Server)*
